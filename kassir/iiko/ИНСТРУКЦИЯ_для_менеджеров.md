# Ежедневный отчёт «Смены кассиров» из iiko → в Telegram

Делается каждый день после закрытия кассовой смены. Занимает 1–2 минуты.

> Названия пунктов меню ниже даны по iikoOffice; в вашей версии они могут чуть отличаться.
> Если поле не находится — ищи его через поиск в списке полей OLAP-отчёта.

## Настройка (один раз)

1. **iikoOffice → Отчёты → OLAP-отчёт по продажам** (может называться «Отчёт по продажам (OLAP)»).
2. Тип отчёта — **Продажи**.
3. Перетащи в **строки (группировка)** поля строго в этом порядке:
   1. Торговое предприятие
   2. Учетный день
   3. Кассир
   4. Номер кассовой смены
   5. Номер чека
   6. Группа блюда
   7. Блюдо
4. В **данные (значения)** — два поля:
   - Количество блюд
   - Сумма со скидкой
5. **Фильтры:**
   - Торговое предприятие — Burger Heroes VKO и Мо Бар VKO (обе точки можно в одном файле);
   - Удалён со списанием / Заказ удалён — **«Не удалён»**.
6. Отключи промежуточные итоги, если есть такая настройка (не обязательно, бот их пропускает).
7. **Сохрани отчёт** под названием **«Смены кассиров»** (кнопка «Сохранить» / «Сохранить как…»),
   чтобы каждый день не настраивать заново.

## Каждый день

1. Открыть сохранённый отчёт **«Смены кассиров»**.
2. Период — **сегодня** (учётный день, который закрыли).
3. Нажать **«Построить»**.
4. **Экспорт → Excel (.xlsx)**. Формат **.xlsx**, не старый .xls.
5. Отправить файл в Telegram-чат с ботом. Подпись не нужна.
6. Бот в ответ пришлёт итоги: выручка и средний чек каждого кассира, выполнен ли план, премия 1,25% или 2%, допродажи.

Если ошиблись и выгрузили не то — просто отправьте исправленный файл за тот же день, бот заменит цифры.

## Команды бота

| Команда | Что делает |
|---|---|
| `/day` | итоги последнего загруженного дня ещё раз |
| `/day 2026-10-09` | итоги за конкретный день |
| `/week` | рейтинг кассиров за 7 дней |
| `/month` | премии кассиров за текущий месяц — для расчёта ЗП |
| `/month 2026-09` | премии за сентябрь |
| `/pax 74350` | **по вторникам:** пассажиропоток МВЛ за прошлую неделю → бот сразу считает СПП |
| `/spp` | СПП за прошлую неделю |

## Если бот ругается

- **«Не найдены колонки…»** — в отчёте не хватает полей из пункта 3–4 настройки.
- **«Старый формат .xls»** — при экспорте выбери .xlsx.
- **«Не понял, к какой точке относятся строки»** — в отчёт не попало поле «Торговое предприятие».
  Добавь его или один раз напиши в чат `/tochka bh` (Burger Heroes) или `/tochka mo` (Мо Бар).
