# Коннектор iiko для приложения «Смена · VKO»

Тянет продажи из iiko по каждому кассиру за день и считает факты смены:
выручку, число чеков, долю чеков с напитком, соусом, комбо и т.д., штуки позиции месяца.
Формат совпадает с `facts` в `kassir/index.html`, так что ручной ввод при закрытии смены больше не нужен.

Работает через **iikoServer API** (OLAP-отчёт «Продажи»). Нужен только Python 3, без библиотек.

## Что нужно получить у IT / поддержки iiko
1. Адрес сервера iiko (вида `https://xxx.iiko.it`).
2. Логин и пароль пользователя с правом смотреть отчёты по точкам VKO
   (лучше отдельный пользователь `api_...`, не личный).
3. Подтверждение, что на сервере есть свободная лицензия на API.

## Настройка
```bash
cp config.example.json config.json   # вписать адрес, логин, пароль
python probe.py                      # проверить связь и имена полей
python probe.py --groups bh          # посмотреть группы блюд Burger Heroes
python probe.py --groups mo          # и Мо Бар
```
По выводу `probe.py` поправить в `config.json`:
- `points.*.department` — точное название подразделения в iiko;
- `points.*.rules` — какие группы или блюда считаются напитком, соусом, комбо и т.д.;
- `fields` — если какое-то поле отмечено ✗, взять правильное из списка похожих.

## Выгрузка
```bash
python pull.py --point bh --date 2026-10-09
```

## Тесты
```bash
python -m unittest test_shift_facts
```

## Ограничения
- Отзывы гостей и проверка скрипта в iiko не хранятся. Отзывы вводятся вручную, скрипт отмечает управляющий.
- Данные берутся за учётный день. Если кассир за день отработал две смены, они сложатся.
