# iiko → итоги кассиров

Два способа получать продажи по каждому кассиру:

| | Как | Когда |
|---|---|---|
| **A. Выгрузка в Telegram** | менеджер после закрытия дня кидает Excel из iikoOffice в бота | сейчас, доступа к API нет |
| **B. Прямой API** | скрипт сам забирает OLAP-отчёт по расписанию | когда дадут доступ к iikoServer API |

Оба способа считают одинаково (`shift_facts.py`): выручка, чеки, средний чек, доля чеков с напитком/соусом/комбо…,
штуки позиции месяца, премия 1,25% или 2% (если выполнен план по выручке), СПП по пассажиропотоку МВЛ.

## A. Telegram-бот (`bot.py`)

Инструкция для менеджеров: [ИНСТРУКЦИЯ_для_менеджеров.md](ИНСТРУКЦИЯ_для_менеджеров.md).

### Запуск
1. Создать бота у [@BotFather](https://t.me/BotFather), получить токен.
2. `cp config.example.json config.json`, вписать токен в `telegram.token`.
3. `pip install -r requirements.txt`
4. `python bot.py`, написать боту `/start` в нужном чате — он покажет ID чата.
5. Вписать ID в `telegram.allowed_chats`, перезапустить. Из других чатов бот ничего не принимает.

Бот работает, пока запущен `bot.py`, поэтому нужен компьютер, который включён постоянно.
Лучше всего VPS в России (300–600 ₽/мес): там ФИО и выручка сотрудников, это персональные данные.

### Настройка под меню (`config.json → points`)
- `match` — по каким словам в колонке «Торговое предприятие» узнавать точку;
- `plans` — план выручки и среднего чека на смену кассира, план СПП;
- `bonus` — проценты премии (база / при выполнении плана);
- `rules` — какие **группы блюд** (`groups`), конкретные **блюда** (`dishes`) или **слова в названии** (`dish_contains`)
  считаются напитком, соусом, комбо и т.д., и план по каждому показателю.

Сверить группы с реальным меню: после первой загрузки посмотреть, какие значения в колонке «Группа блюда».

## B. Прямой API (`pull.py`, `probe.py`)
Нужны адрес сервера iiko, логин/пароль с правом на отчёты и свободная лицензия API.
```bash
python probe.py              # проверить связь и имена полей
python probe.py --groups bh  # группы блюд точки
python pull.py --point bh --date 2026-10-09
```

## Тесты
```bash
python -m unittest test_shift_facts test_export
```

## Ограничения
- Отзывы гостей и проверка скрипта сервиса в iiko не хранятся. В бот пока не попадают.
- Данные считаются за учётный день. Если кассир отработал за день две смены, они сложатся.
